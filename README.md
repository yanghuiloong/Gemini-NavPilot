## ✨ 核心功能

### 1. ⚡ 快速滚动跳转（蓝色箭头）
- **极速回到顶部/底部**: 无论是查看最新回复还是回顾开始的对话，点击即达。
- **智能感知显示**: 
  - **向下滑动**时 → 显示 **蓝色向下箭头**（跳至底部）。
  - **向上滑动**时 → 显示 **蓝色向上箭头**（跳至顶部）。
- **自动隐藏**: 停止滚动 **3秒** 后自动淡出，保持界面清爽。
- **贴心布局**: 悬浮于屏幕右下角，完全不遮挡输入框。

### 2. 💬 提问导航器（悬浮面板）
- **历史提问快速切换**: 专为您设计的导航面板，只在您发送的“提问节点”之间跳转。
- **精准控制**:
  - **向上 (▲)**: 跳转到上一个提问。
  - **向下 (▼)**: 跳转到下一个提问。
- **智能跟随布局**: 
  - 面板会自动**吸附在输入框的“模型选择按钮”右侧**。
  - 无论窗口如何缩放，它始终紧贴输入框，保持完美的视觉一致性。
- **精致 UI 设计**:
  - **磨砂玻璃质感**: 采用 `backdrop-filter` 模糊背景，完美融入 Gemini 的界面风格。
  - **Google 蓝配色**: 按钮采用经典的 Google Blue (`#4285f4`)。
  - **智能禁用状态**: 当到达第一条或最后一条提问时，按钮自动变灰，防止误操作。
  - **智能偏移**: 跳转时会自动预留 **180px 顶部空间**，确保您发送的图片或截图也能完美展示，不会被遮挡。

## 📦 安装指南

1. **下载/克隆** 本项目到本地。
2. 打开 Chrome 浏览器，访问 `chrome://extensions`。
3. 开启右上角的 **开发者模式 (Developer mode)**。
4. 点击左上角的 **加载已解压的扩展程序 (Load unpacked)**。
5. 选择包含 `manifest.json` 的 `Gemini NavPilot` 文件夹。
6. 打开 [gemini.google.com](https://gemini.google.com)，开始体验丝滑导航！

---

## 🛠 技术亮点

- **智能元素追踪**: 使用 `requestAnimationFrame` 实时计算并追踪页面上的特定元素（如模型选择按钮），实现比 CSS 更精准的动态吸附效果。
- **强力滚动检测**: 使用 `capture: true` (捕获阶段) 监听器，完美解决单页应用 (SPA) 中复杂嵌套容器滚动检测失效的问题。
- **基于索引的导航算法**: 实时追踪当前位置索引，确保“上一个/下一个”跳转逻辑严丝合缝，不会卡在当前位置。

---

## 📂 项目结构

- `manifest.json`: Chrome 扩展配置文件 (Manifest V3)。
- `content.js`: 核心逻辑（滚动监听、元素追踪、导航算法）。
- `styles.css`: 悬浮面板样式、动画效果（位置由 JS 动态控制）。
